# اختصارات الكيبورد على الآيفون

**الإعداد:** الإعدادات ← عام ← لوحة المفاتيح ← استبدال النص ← (+)
- **العبارة:** النص الكامل
- **الاختصار:** الكلمة القصيرة

بعدها، كتابة الاختصار في تطبيق Claude ثم مسافة تكتب الطلب كاملاً.

| الاختصار | العبارة |
|---|---|
| `خطه` | `استراتيجي: جهّز الخطة الشهرية للشهر القادم لعميل: ` |
| `كبش` | `محتوى: اكتب كابشنات عربي وإنجليزي لمنشورات هذا الأسبوع لعميل: ` |
| `ريل` | `محتوى: اكتب سكربت ريل 30 ثانية عربي وإنجليزي عن: ` |
| `تقو` | `سوشيال: حوّل الخطة المعتمدة إلى تقويم محتوى للشهر وأعطني CSV` |
| `متا` | `سوشيال: ما المحتوى المتأخر أو المنتظر موافقة هذا الأسبوع؟` |
| `بري` | `إبداعي: جهّز بريف Canva وبرومبت صورة لكل منشورات هذا الأسبوع لعميل: ` |
| `تقر` | `تحليلات: هذه تقارير Insights الحقيقية. استخرج الأرقام كما هي واطلب تأكيدي قبل كتابة التقرير الشهري لعميل: ` |
| `اول` | `حسابات: أعطني أولويات هذا الشهر وتسليمات كل عميل` |
| `يوت` | `يوتيوب: 5 أفكار فيديو مع العناوين والأوصاف وخطة إعادة تدوير عن: ` |

> ملاحظة: إن تعارض اختصار مع كلمة تُكتب كثيراً، يمكن إضافة رمز قبله مثل `؛خطه`.
