## البوست ٤: «لما يقول ما بدّي!»
```
«ما بدّي!»… أكثر جملة بتسمعها أمّ طفل بعمر الأربع سنين 😅

العناد مش قلّة أدب. طفلك عم يكتشف إنّه إله رأي، و«ما بدّي» هي طريقته الوحيدة ليقول: «أنا موجود… وبدّي أقرّر».

فبدل ما ندخل معه بمعركة، نعطيه قرار صغير:
✓ «بدّك الأزرق ولا الأحمر؟»
✓ «بدّك قصة ولا قصتين قبل النوم؟»
✓ «بدّك تطلع من الحمّام بقفزة ولا مشي؟»

الخيار الصغير بيعطيه إحساس بالسيطرة… والقرار الكبير بيضل إلكِ.

قال ﷺ: «إنّ الرِّفقَ لا يكونُ في شيءٍ إلا زانَه، ولا يُنزَعُ من شيءٍ إلا شانَه» (رواه مسلم).

احفظي البوست 🔖 وجرّبيه بكرا الصبح، واحكيلي شو صار 👇

#أم_وأمة #عناد_الأطفال #تربية_إسلامية #تربية_الأطفال #أمهات
```

## البوست ٥: «فنّ التحدّث مع الأطفال»
```
كتاب غيّر طريقة كلامي مع ولادي 📚

«فنّ التحدّث مع الأطفال» لأديل فابر وإلين مازليش.
الفكرة الأهم فيه: الطفل ما بيسمعنا… قبل ما يحسّ إنّنا سمعناه.

يعني: سمّي الشعور قبل ما تحلّي المشكلة.
✕ «ما في شي بيخوّف!»
✓ «شكلك خايف… الصوت كان عالي، صح؟»

✕ «ليش ضربت أخوك؟!»
✓ «كنت معصّب كتير… احكيلي شو صار»

جرّبتها مع ابني الكبير، وأول مرة شفت فيها الفرق: بدل ما يصرّخ أكثر، سكت… وصار يحكي.

لمّا الطفل يحسّ إنّه مفهوم بيهدأ، ولمّا يهدأ بيسمع 🤍

احفظيه 🔖 وشاركيه مع أمّ بتحبّيها.

#أم_وأمة #كتب_تربية #تربية_واعية #تربية_الأطفال #أمهات
```

## البوست ٦: «الساعة ٣ فجراً»
```
الساعة ٣ فجراً… 🌙

البيت نائم، وأنا وصغيرتي والقمر.
تعبٌ لا يراه أحد، ولا يشكرني عليه أحد.

لكنّ الله رأى… وذكره في كتابه:
﴿حَمَلَتْهُ أُمُّهُ وَهْنًا عَلَىٰ وَهْنٍ﴾ [لقمان: ١٤]

لكلّ أمّ ساهرة الليلة: تعبكِ مكتوب، وسهركِ مش ضايع.
لستِ وحدكِ 🤍

اكتبي «🤍» إذا إنتِ كمان صاحية هلّق 👇

#أم_وأمة #الأمومة #أمهات #يوميات_أم
```
